Command line

Install command-line tool

Links the bundled binary as mergeiq in a folder of your choice.

~/.local/bin is not on your PATH. Add this to ~/.zshrc: export PATH="$HOME/.local/bin:$PATH"

Configure as git mergetool

These commands change your global git config. Nothing runs until you confirm.

git config --global merge.tool mergeiq
git config --global mergetool.mergeiq.cmd 'mergeiq merge "$BASE" "$LOCAL" "$REMOTE" "$MERGED"'
git config --global mergetool.mergeiq.trustExitCode true
git config --global mergetool.keepBackup false

Usage

mergeiq open <dir>Open a repository window mergeiq resolve <path>Resolve one conflicted file, or a file with conflict markers mergeiq merge B L R MMergetool mode. Exits 0 when resolved, 1 when cancelled or saved with markers
