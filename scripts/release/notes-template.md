## Install

{{install_table}}

Verify a download with `sha256sum --check SHA256SUMS.txt` (macOS: `shasum -a 256 --check SHA256SUMS.txt`) in the folder holding the files you downloaded; every file you have should report `OK`.

After installing, **Settings › Command line** adds the `mergeiq` command and the `git mergetool` setup. See [docs/git-integration.md](https://github.com/{{repo}}/blob/{{tag}}/docs/git-integration.md).
